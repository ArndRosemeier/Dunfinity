# Season a skill with salt

- Salt keeps its worth once every card is cooked: in grandma's tin, each skill you have practised has a "Season · 1 pinch" button.
- A pinch is worth that skill's own step of uses, so the next level takes as many pinches as its number (level 5: five pinches). Use still counts too.
- Only skills you have practised at all can be seasoned. Like the skills, what the salt bought goes with the grandchild.
