# Open-ended skills for every ability

- Every ability now has a skill that grows with use: all of grandma's cards, plus running, swimming and leaping.
- Skills have no top level. Each level takes a few more uses than the last (level n takes step × n), never exponentially more.
- Each level adds a small fixed step to damage and how long things last, and makes cooldowns and stamina costs a little cheaper (never free).
- Only uses that did something count: a blow that landed, a flame that burnt something, a cloud that went up.
- The tin shows each skill practised with its level and a bar towards the next.
- Skill gear now gives three levels (sound), and any skill can turn up as a property on gear found below.
- Skills are lost when a grandchild dies, like the cards they cooked.
